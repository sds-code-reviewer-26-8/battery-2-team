## 5. 결정이 필요한 점 (미결)

1. **[미결] 취소한 주문을 남길 것인가?**
   - 설명 자료는 취소를 상태로 본다. 코드는 삭제한다. 목록의 "취소" 필터는 삭제된 주문이 없으므로 항상 0건이 될 것으로 보인다(이력만 남음).
   - 선택지: (a) 삭제 유지 + 취소 필터 제거, (b) 주문을 남기고 상태만 `취소`로 변경.
   - 영향: I11(이력), 취소 직후 화면 오류(§4), `OrderFlowTests`.
2. **[미결] 생산 물량을 시스템이 배분할 것인가?** 설명 자료는 시스템이 배분하고, 현재는 담당자가 입력한다. 자동 배분이 들어오면 입력 화면(게이지)과 `simulate`의 입력이 바뀐다.
3. **[미결] 공장 운영비를 어떻게 반영할 것인가?** 하루 단위인지, 주문 건당인지, 월 고정인지에 따라 최적 경로와 3가지 안의 비교가 달라진다.
4. **[미결] 고객사·납기를 어떻게 쓸 것인가?** 입력만 받을지, 납기를 넘기는 경로를 걸러 주거나 경고할지.
5. **[미결] "완료"의 기준.** 수동 변경으로 둘지, 배의 한국 도착 일정과 연결할지.
6. **[미결] 로그인과 권한.** 고정 계정이 임시인지, 담당자/관리자 역할을 나눌지. 설명 자료는 "관리자가 상태를 변경"한다고 한다.
7. **[미결] 생산원가 허용 범위.** 설명 자료는 500~1,000원 수준이고 기본값 중 인도네시아는 450원이다. 입력 허용 범위(1~1억 원)를 좁힐지.
