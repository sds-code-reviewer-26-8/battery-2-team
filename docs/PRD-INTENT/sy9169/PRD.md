## 1. 배경과 문제

- 한국 본사를 둔 DSD는 전기차용 원통형 배터리 셀(2170)을 **중국·일본·베트남·인도네시아 4개국의 자체 공장**에서 생산해 공급한다. [설명]
- 공장마다 **하루 최대 생산량**, **재고 창고 용량**, **셀당 생산원가**가 다르다. 완제품은 각 공장 창고에 쌓이고 출고 전까지 보관된다. [설명]
- 완성된 셀은 DSD가 **1~4척의 화물선을 빌려** 한국으로 운송한다. 배 임차료는 척당 하루 약 1억 원이며, **한국 항만에 정박해 있는 동안은 비용이 없다.** 선박 적재량은 충분하다. [설명]
- 고객 주문(예: 15,000K)이 들어오면 **어느 공장에 얼마를 배분할지**, **배를 어떻게 운영할지**를 정해야 하고, 두 결정이 얽혀 있어 사람이 바로 판단하기 어렵다. [설명]

**목표:** 주문 수량을 입력하면 배 운영 계획을 **비교 가능한 3가지 안**으로 계산해 보여 주고, 담당자가 하나를 골라 **주문으로 확정**하고 그 이후의 **상태를 관리**할 수 있게 한다.

## 5. 계산 규칙 (바뀌지 않는 규칙)

[코드] 규칙은 `Planner` 와 `PlannerTest` 로 확인했다.

1. **동시 생산:** 0일차에 모든 공장이 동시에 생산을 시작한다.
2. **하루 생산량** = min(하루 최대 생산량, 창고 상한 − 현재 재고, 남은 주문량). 창고가 차면 수거 전까지 멈춘다.
3. **수거:** 배는 도착 시점의 재고를 **전부** 싣는다.
4. **한 나라는 한 척의 배만 방문한다.**
5. **방문 횟수** = 올림(주문량 ÷ 재고 상한). 마지막 방문 전까지는 상한만큼, 마지막은 나머지를 싣는다.
6. 여러 번 수거할 때 배는 **한국에 내려놓고 다시 출항**한다.
7. 배는 재고가 채워지는 날에 맞춰 **늦게 출항**한다. 한국에서의 대기는 무료다. [설명]과 일치
8. **비용**
   - 생산 원가 = 수량(K) × 1,000 × 나라별 셀당 원가
   - 운항비 = 배들이 실제로 항해한 일수의 합 × 척당 하루 운항비 (한국 대기일은 제외)
   - 총 비용 = 생산 원가 + 운항비 (공장 운영비는 F10 이전까지 미포함)
9. **총 소요일** = 마지막 배가 한국에 돌아오는 날.
10. **3가지 안의 정의**
    - 운항비 최소: 운항비가 가장 낮은 안. 같으면 더 빠른 쪽
    - 가장 빠르게: 총 소요일이 가장 짧은 안. 같으면 더 저렴한 쪽
    - 가까운 곳부터: 한국에서 가까운 나라부터 배에 번갈아 배정하는 **단순한 비교 기준 안**(최적 아님)
11. **불변 조건:** 어떤 안이든 (a) 배가 실은 양의 합 = 나라별 주문량, (b) 재고는 창고 상한을 넘지 않음, (c) 총 비용 = 생산 원가 + 운항비.

**숫자로 확인한 예 (기본 마스터, 배 1척, 일 운항비 1억 원)** [코드: `PlannerTest`]

| 주문 | 결과 |
| --- | --- |
| 중국 400K | 생산 1일, 1일차 도착, **2일차 귀환**, 운항비 2억 원 |
| 베트남 2,000K | 생산 10일, **5일차 출항**, 10일차 도착, **15일차 귀환**, 운항비 10억 원 |
| 일본 4,500K (상한 2,000K) | 방문 3번: 2,000 / 2,000 / 500 |

## 6. 주문 상태

```
확정 ──▶ 진행 ──▶ 완료
 │        │
 └──▶ 취소 ◀┘
```

| 상태 | 업무 의미 [설명] |
| --- | --- |
| 확정 | 고객사와 소통해 **구두로 확정**된 상태. 최초 상태 |
| 진행 | **계약서 작성 후** 공장 생산과 운영을 시작한 상태 |
| 완료 | 생산이 끝나고 **물량이 한국에 모두 들어온** 상태 |
| 취소 | 어떤 사정으로 취소된 상태. **확정·진행 중에만** 가능 |

- 허용되는 변경은 확정 → 진행·취소, 진행 → 완료·취소뿐이다. 건너뛰기와 되돌리기는 없고, 완료와 취소는 최종 상태다. [코드]
- **[확인 필요]** 취소하면 코드는 주문을 **삭제**하고 이력만 남긴다. 설명 자료는 취소를 "하나의 상태"로 본다. §10-1
- **[확인 필요]** "완료"는 지금 관리자가 수동으로 바꾸는 값이며, 실제 입고와 연결되어 있지 않다. §10-5
