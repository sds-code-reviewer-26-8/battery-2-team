코드를 몰라도 되는 3단계 안내입니다. 탭을 순서대로 눌러 보세요.

한 문단 요약

배터리 공장이 중국·일본·베트남·인도네시아에 하나씩 있습니다. 이 배터리를 배로 한국에 모아 옵니다. 나라별로 필요한 수량을 입력하면, 앱이 어떤 배가 어떤 순서로 돌지 3가지 안을 계산해 줍니다. 한 안을 고르면 주문이 확정되고, 이후에는 주문의 진행 상태를 관리합니다.

수량 단위 K = 1,000개(셀). 예: 3,000K = 300만 개.

꼭 알아둘 규칙

  • 생산: 모든 공장이 주문 첫날(0일차)에 동시에 생산을 시작합니다. 하루에 만들 수 있는 양이 정해져 있습니다.
  • 창고 한도: 공장 창고가 가득 차면 생산이 멈춥니다. 배가 실어 가야 다시 만들 수 있습니다.
  • 배: 기본 3척, 최대 4척. 배가 운항하는 날마다 비용이 듭니다. 한국 항구에서 기다리는 것은 공짜입니다.
  • 방문: 한 나라는 한 척의 배만 방문합니다. 도착하면 그 시점의 재고를 전부 싣습니다.
  • 여러 번 나눠 싣기: 주문이 창고 한도보다 크면 여러 번 방문해야 합니다. 이때 배는 한국에 내려놓고 다시 출항합니다.

수량 게이지 체험 슬라이더를 움직여 보세요

주문 추가 화면의 게이지 규칙입니다. 한 나라를 움직이면 바로 오른쪽 나라가 반대로 조정되고(맨 오른쪽은 맨 왼쪽), 합계는 항상 총 수량과 같습니다.

주문 상태 체험 버튼을 눌러 보세요

확정된 주문의 상태는 정해진 순서로만 바뀝니다. 건너뛰기나 되돌리기는 안 됩니다.

처음 상태는 항상 '확정'입니다.

변경 이력

    여러 사람이 동시에 쓰면?

    두 사람이 같은 주문을 동시에 보고 있다가 한 명이 먼저 상태를 바꾸면, 늦게 누른 사람은 "다른 사용자가 먼저 변경했습니다. 화면을 새로 고쳐 주세요" 안내를 받고 변경이 거부됩니다. 마스터(공장·항로·배 정보)가 바뀐 경우도 같습니다. 시뮬레이션 이후 정보가 바뀌었다면 확정되지 않고 다시 계산해야 합니다.

    확인이 필요한 점: 취소하면 주문이 사라진다

    주문을 취소하면 주문 자체가 삭제되어 목록·상세에서 볼 수 없습니다. 이력에는 "→ 취소"가 남지만 어느 주문의 이력인지 확인할 화면이 없습니다. 반면 목록에는 "취소 N건" 필터가 있어 서로 어긋나 보입니다.

    • 취소한 주문도 기록으로 남겨야 하는가?
    • 아니면 삭제가 의도인가? (그렇다면 "취소" 필터는 필요한가?)

    ※ 코드에서 읽은 사실이며, 아직 요구사항으로 확정된 내용이 아닙니다.

    마스터 화면은 무엇인가

    계산에 쓰이는 기준 정보를 고치는 화면입니다: 배 척수(1~4), 척당 하루 운항비, 공장별 하루 최대 생산량·창고 한도·개당 원가, 나라 사이 항해 일수. 값을 저장하면 이후 시뮬레이션부터 새 값이 적용되며, 이미 확정된 주문은 확정 당시의 값으로 보존됩니다.

    주문 수량 계산기 수량을 바꿔 보세요

    나라별 필요 수량(K)을 입력하면 몇 번 나눠 실어야 하는지, 비용은 얼마인지 바로 보여 줍니다. (마스터 기본값 기준)

    ※ 이 계산기는 개념 이해용입니다. 실제 앱은 여기에 배 배정, 출항 시점, 운항비까지 더해 최적 경로를 계산합니다.

    한 나라 왕복 체험 슬라이더를 움직여 보세요

    3가지 안, 무엇이 다른가

    ① 운항비 최소

    배를 이용하는 총 일수가 가장 적은 안. 돈을 아끼는 선택입니다. 비용이 같으면 더 빠른 쪽을 고릅니다.

    ② 가장 빠르게

    모든 배가 한국에 돌아오는 날이 가장 이른 안. 급할 때의 선택입니다. 날수가 같으면 더 저렴한 쪽을 고릅니다.

    ③ 가까운 곳부터

    한국에서 가까운 나라부터 배에 차례로 나누어 배정하는 단순한 안. 비교 기준용입니다.

    각 안에 표시되는 것

    • 총 소요일 (주문일부터 마지막 배가 돌아오는 날까지)
    • 생산비 + 운항비 = 합계 비용
    • 배별 일정: 언제 출항해서 어느 나라에 며칠에 도착하고 몇 K를 싣는지
    • 나라별 일별 재고·생산량 그래프

    생산비는 어느 안을 골라도 같고(수량 × 개당 원가), 안마다 달라지는 것은 운항비와 소요일입니다.
